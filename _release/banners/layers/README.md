# 三张发布横幅可编辑图层包

画布统一为 `1920 × 1080`。每个横幅目录都包含：

- `background.png`：不含主体 UI 和宣传元素的干净背景板。
- `elements/`：已经分离、带透明通道的 PNG 元素。
- `layout.json`：推荐初始位置、显示尺寸和图层顺序，坐标原点为画布左上角。
- `preview.png`：使用当前图层与 `layout.json` 推荐参数重组的参考图。
- `asset-sheet.png`：营养值、口渴值素材的透明总表，方便需要时重新裁切；实际排版优先使用 `elements/`。

## 使用方式

1. 新建 `1920 × 1080`、sRGB 画布，把对应目录的 `background.png` 放在最底层。
2. 按 `layout.json` 中由小到大的 `zIndex` 导入 `elements/` 文件。
3. `x`、`y` 是元素左上角坐标，`width`、`height` 是预览使用的显示尺寸；这些参数只是推荐起点，可以任意移动、缩放或隐藏。
4. 导出时保留 16:9，最终使用 PNG 或最高质量 JPG。

## 各横幅拆分内容

### nutrition / 营养值

- 原版均衡饮食界面面板。
- 苹果、面包、熟牛肉三种食物特写。
- 水果、谷物、蛋白质三条独立营养进度条。
- 三组对应颜色的增益粒子。

### thirst / 口渴值

- 水瓶、泼水轨迹、十格口渴水滴、HUD 四个主要元素。
- 额外提供 `thirst-drop-single.png`，可自行复制并制作任意格数的口渴进度。
- `thirst-drops-10.png` 已校正为恰好十格；总素材表中保留了生成底稿，排版时不要直接用总表中的十一格水滴。

### disease / 疾病系统

- 左侧均衡饮食／疾病说明面板。
- 低血糖、高血糖、便秘、佝偻病、发热、口腔溃疡、坏血病七个独立发光节点。
- `connections-full-canvas.png` 和 `divider-full-canvas.png` 为透明全画布覆盖层，放在 `(0, 0)` 即可；需要完全自由排线时可以隐藏这两层并自行绘制。

`preview.png` 只用于核对图层是否齐全，不会覆盖原有三张发布横幅。
